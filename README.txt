HACKER TERMINAL (interaktiv xaker simulyatori)
===========================================
Ochish: hacker-terminal.html ni Chrome'da oching (ikki marta bosing yoki Live Server), F11 = to'liq ekran.
Rasmlar photos/ papkasidan o'zi olinadi (hacker-terminal.html bilan yonma-yon tursin).

MAXFIY KOD: shadow protocol 7   (o'zgartirish: html faylni Notepad bilan ochib, boshidagi CONFIG qismida SECRET_CODE)

TUGMALAR
  F2  - maxfiy kodni avtomatik yozadi
  F3  - Photo Manager (qo'shimcha rasm yuklash, EXPORT ZIP bilan saqlab olish)
  F4  - tovush yoq/o'chir
  Esc - oynani yopish        Up/Down - oldingi buyruqlar

RASMLAR: photos/male|female/young|mid|senior/1.jpg, 2.jpg ...  (young 18-29, mid 30-44, senior 45+)
Yangi rasm qo'shsangiz, nomlarini ketma-ket (1.jpg, 2.jpg, ...) qiling.

TOZA EKRAN: CONFIG qismida SHOW_HINTS = false qilsangiz, ekrandagi tugma yozuvlari yo'qoladi.
Barcha ism, pasport, telefon, manzil ma'lumotlari tasodifiy to'qiladi va hech kimga tegishli emas.
